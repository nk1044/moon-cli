What is Moon CLI?

Moon CLI is a lightweight command-line tool that helps you create aliases for long and repetitive commands. Stop typing the same complex commands over and over—save them once, run them with a simple alias.

Installation

brew tap nk1044/moon-cli
brew install moon

Install via Homebrew (macOS & Linux)

go install github.com/nk1044/moon-cli@latest

Requires Go 1.21 or later

# Download the binary for your OS from GitHub releases
curl -L https://github.com/nk1044/moon-cli/releases/latest/download/moon-[OS]-[ARCH] -o moon

# Make it executable
chmod +x moon

# Move to PATH
sudo mv moon /usr/local/bin/

Replace [OS] and [ARCH] with your system (e.g., linux-amd64, darwin-arm64)

Quick Start

moon — bash
# Create a new alias
$ moon create deploy

# Add commands to the alias
$ moon add deploy "git pull origin main"
$ moon add deploy "docker-compose up -d"
$ moon add deploy "npm run build"

# List all your aliases
$ moon list

# Run commands from an alias (interactive selection)
$ moon deploy

# Edit commands in an alias
$ moon edit deploy

# Delete an alias
$ moon delete deploy

Features

Simple & Fast

Create, manage, and run command aliases with minimal keystrokes. No configuration files needed.

Interactive Selection

Choose which command to run from your alias with an intuitive arrow-key interface.

Clipboard Integration

Selected commands are automatically copied to your clipboard for easy pasting.

Cross-Platform

Works seamlessly on macOS, Linux, and Windows. Write once, use everywhere.

Lightweight

Single binary with no dependencies. Fast startup and minimal resource usage.
