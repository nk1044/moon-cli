What is Moon CLI?

Moon CLI is a lightweight command-line tool that helps you create aliases for long and repetitive commands. Stop typing the same complex commands over and over—save them once, run them with a simple alias.

Building & Installation

git clone https://github.com/nk1044/moon-cli.git
cd moon-cli
go build -o moon

Requires Go 1.21+

sudo mv moon /usr/local/bin/
moon --help

Add to PATH on macOS

sudo mv moon /usr/local/bin/
moon --help

Add to PATH on Linux

move moon.exe "C:\Program Files\moon\"
moon --help

Add to PATH on Windows

Quick Start

moon — bash
# Create a new alias
$ moon create deploy

# Add commands to the alias
$ moon add deploy "git pull origin main"
$ moon add deploy "docker-compose up -d"

# List all your aliases
$ moon list

# Run commands (interactive)
$ moon deploy

Features

Simple & Fast

Create and run command aliases with minimal keystrokes. No config files needed.

Interactive Selection

Choose commands with an intuitive arrow-key interface.

Clipboard Integration

Commands are automatically copied to clipboard.

Cross-Platform

Works on macOS, Linux, and Windows seamlessly.

Lightweight

Single binary with no dependencies. Fast and minimal.
